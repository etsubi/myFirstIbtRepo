# Qené Residences

A boutique hotel booking website built as my final JavaScript Module project.

## Features

- Browse available hotel rooms
- Search for rooms
- Filter rooms by category
- Filter rooms by maximum price
- Select number of nights and guests
- Reserve rooms
- View reservations
- Remove bookings
- Save booking and reservation data using localStorage
- Responsive user interface

## Technologies

- HTML
- CSS
- JavaScript
- localStorage
