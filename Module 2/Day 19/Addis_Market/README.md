# Addis Market Shopping List

## What it does

Addis Market is a simple interactive shopping list built with HTML, CSS and JavaScript.

Users can:

- Add shopping items
- Enter an ETB price
- Mark items as bought
- Delete items
- See a live running total

## Technologies

- HTML
- CSS
- JavaScript

## DOM Concepts Used

This project uses:

- querySelector()
- textContent
- createElement()
- append()
- addEventListener()
- event.target
- event delegation
- classList.toggle()
- preventDefault()

## How to Open

Open `index.html` in a web browser.

## Project Structure

### index.html

Contains the structure of the shopping list and form.

### styles.css

Contains the styling, including the bought item state.

### app.js

Contains the DOM manipulation, event handling, item creation, deletion and total calculation.
