- ES modules

## TeleBirr Transaction Report

The mini-project generates a report for TeleBirr transactions.

### transactions.js

Contains the transaction data.

Each transaction has:

- id
- customer
- amount
- type

### report.js

Contains reusable functions for:

- calculating totals by transaction type
- formatting transaction receipts
- creating updated transaction copies

### app.js

Imports the transaction data and report functions, then prints the final report.
